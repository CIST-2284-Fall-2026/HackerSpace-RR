# .NET 10 Blazor Web App

## About This Project

This project is a .NET 10 Blazor web application created for my CNM .NET II/C# class.

The purpose of this assignment was to learn how to create a Blazor application using the .NET CLI and work with the basic project structure.

## Features

This project includes:

- .NET 10 Blazor
- Interactive Auto render mode
- Individual User Accounts
- ASP.NET Core Identity
- SQLite database
- User registration and login
- Authentication and authorization
- Server and client Blazor projects
- Entity Framework Core migrations

## What I Worked On

For this assignment, I created the Blazor application using the .NET CLI and tested that the project builds and runs correctly.

I also explored the SQLite database used for user authentication and looked at the tables created by ASP.NET Core Identity.

The project includes both:

- `BlazorWebApp`
- `BlazorWebApp.Client`

The solution file is:

`BlazorWebApp.sln`

## What I Learned

This assignment helped me understand how a Blazor project is organized and how the server and client portions work together.

I also learned more about how ASP.NET Core Identity uses a SQLite database for user accounts and how migrations are used to create the database structure.

I was also able to practice using the .NET CLI, VS Code, Git, and GitHub as part of the development workflow.
